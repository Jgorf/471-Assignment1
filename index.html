Top 10 Crime Types by Number of Crimes

Number of Crimes by Year (2020 - 2026)

For Assignment 1, we used the Chicago crime dataset but created a subset to only look at the years 2020 to 2026. We decided to only look at the variables crime type, year, location, and arrest rate (%). We made the subset and calculated the arrest rate by using python and the pandas module. The goal of our visualization was to let the users explore how the number of reported crimes varies by crime type, year (quarterly), and location (street, apartment, etc.).

We created two charts for this assignment. The first chart is a bar chart that shows the number of reported crimes by the top 10 crime types. The number of crimes committed is on the x-axis and crime type is on the y-axis so the user can easily compare the different crime types. The second chart is a line chart to show the number of reported crimes over time (years/quarters). We decided to use a line chart because it makes it easy for the user to see trends over time. We put the number of crimes committed on the y-axis and years/quarters on the x-axis so the user can compare how it changes over the years. On the line chart, there is a clear drop off for 2026 as we are still in Q3 of that year. We considered doing a map instead but decided that the bar and line charts make it easier for the user to compare crime types and explore changes over the years.

We created a dropdown so the user can filter by location for both of the charts. The user can choose streets, apartments, residence, sidewalk, parking lot / garage (non residential) or all locations. We also implemented brushing and linking that lets the user brush over a range of years on the line chart to update the bar chart to show data for only that time period. Also, when the user hovers over one of the bars a tooltip displays the arrest rate and other summary data for that crime type. The bar is also highlighted when the user is hovering over it to make it easy for the user to tell which bar they are looking at. These allow the users to explore the data and get more information without overcrowding the charts.
